# Crime Pattern Prediction and Mapping

Machine Learning-based crime analysis project focused on predicting crime patterns, identifying hotspots, and visualizing crime data through interactive mapping and dashboards. Integrated an AI chatbot to answer crime-related queries using predictive analytics and data insights.

## Features
- Crime pattern prediction
- Crime hotspot visualization
- Interactive dashboard
- AI chatbot for crime-related queries
- Data analysis and reporting

## Technologies Used
- Python
- Machine Learning
- Flask
- HTML/CSS/JavaScript
- Pandas
- Scikit-learn
- Power BI / Visualization Tools

## Project Structure
- templates/ → HTML pages
- static/ → CSS & JavaScript files
- ml_model.py → Machine learning model
- ai_assistant.py → AI chatbot
- app.py → Main application

## Future Improvements
- Real-time crime data integration
- Advanced AI recommendations
- Interactive geospatial mapping
